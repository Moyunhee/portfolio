해당 화면에 적용한 기준

이 화면도 아래 기준으로 만들었어요.

  • 시맨틱 마크업

    header, nav, main, section 구조와 제목 위계를 지켜요.

  • 웹접근성

    키보드 조작, 포커스 표시, ARIA, 건너뛰기 링크, 4.5:1 이상의 색 대비를 적용했어요.

  • 반응형

    모바일, 태블릿, 데스크탑 중단점에 맞춰 레이아웃과 이미지가 바뀌어요.

  • SCSS 구조

    변수, 믹스인, BEM 컴포넌트로 나눠 관리해요.

  • 다크 모드

    색상 토큰(CSS 변수)만 바꿔 테마를 전환해요.

  • 사용자 설정 존중

    동작 줄이기 설정과 글자 크기 설정을 따라요.
